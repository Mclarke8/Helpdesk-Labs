Helpdesk-Labs is a collection of hands-on IT support exercises I completed to build real troubleshooting experience. Each lab simulates an actual Helpdesk scenario — things like incident reports, account access issues, network problems, software installs, and root‑cause analysis. I approached each lab the same way I would in a real environment: documenting the issue, walking through the troubleshooting process, verifying the fix, and writing up the resolution clearly and professionally.

The purpose of this repo is to show how I think through problems, communicate with users, and follow structured workflows. It demonstrates my ability to diagnose issues, document tickets, analyze root causes, and apply Helpdesk best practices. Even though these are labs, the work reflects the same responsibilities I’d have in an entry‑level Helpdesk or IT Support role.
